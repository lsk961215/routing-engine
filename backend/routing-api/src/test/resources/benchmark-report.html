진한 막대: 중앙값(p50) · 옅은 막대 끝: p95. JVM과 실행 위치를 바꿔 편차를 확인할 수 있습니다.

Dijkstra 대비: 시간은 기준 중앙값 ÷ 해당 중앙값(1× 미만이면 느림), 나머지는 (1 − 해당 중앙값 ÷ 기준 중앙값) × 100% 감소율입니다. 음수는 증가, 기준값 0은 계산 불가입니다.

탐색 스레드가 할당한 힙 메모리의 추정 누계이며 현재·최대 점유량이 아닙니다. 1 MiB = 1,048,576 B. 측정 불가 표본은 제외하고 표본 수를 유효/전체로 표시합니다.

측정 조건

간선 검사는 확장 상태의 출발 간선을 통행·회전 제한 검사 전에 센 횟수이며 초기 출발 후보는 제외합니다. 양방향 Dijkstra의 확장·검사 횟수는 양쪽 합계이며, 최대 큐 크기도 두 큐에 동시에 저장된 항목의 합계입니다. 최대 큐 크기는 초기 후보와 오래된 항목을 포함한 큐 항목 수의 최댓값이며 메모리 바이트가 아닙니다.

통계와 해석

각 JVM에서 모든 질의를 워밍업한 뒤 동일 횟수로 측정합니다. 한 질의의 두 알고리즘은 도로에 연결된 좌표를 공유하며 순차 실행합니다. 먼저 실행하는 알고리즘은 매 라운드 교대하고, 질의 순서는 고정 시드로 섞습니다.

중앙값은 짝수 표본에서 가운데 두 값의 평균입니다. p95는 정렬 후 ceil(0.95 × 표본 수)번째 값입니다. 이상값을 제거하지 않으며 자연 발생한 GC 시간도 포함합니다. 표준편차는 모집단 기준입니다.

메모리 할당량은 JVM의 현재 스레드 할당량 카운터 차이입니다. GC로 회수한 메모리도 누계에 포함하며 다른 요청 스레드의 할당은 포함하지 않습니다. 미지원·비활성 카운터와 가상 스레드는 측정 불가(null)로 기록합니다.

고정 횟수 워밍업이 JIT 안정화를 보장하지는 않습니다. 운영체제의 다른 작업·온도·GC·실행 순서가 결과에 영향을 줄 수 있습니다. 각 JVM과 실행 위치의 결과를 함께 확인하세요. 이 결과는 로컬 경로 탐색 비용이며 서버 처리량이나 동시 접속 성능을 의미하지 않습니다.
